# Myodyssey

Project page of **Myodyssey: A Muscle-Driven Motion Generalist Trained through a Differentiable Musculoskeletal World Model**
(Yifei Yuan, Xianlian Zhou; New Jersey Institute of Technology).

This repository holds only the static project page and its precomputed simulation results (body poses and muscle
activations of the policy in physics simulation). It contains no code, no model weights and no motion capture data.
